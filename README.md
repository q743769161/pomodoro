# 番茄专注钟 🍅

单文件 Cloudflare Worker：纯静态、无 R2/KV、无密钥，部署即用。

## 功能
- 专注 / 短休息 / 长休息三模式自动流转（默认 25 / 5 / 15 分钟，4 个番茄后长休息）
- 大圆形进度环倒计时，浏览器标签页标题实时显示剩余时间
- 可调时长（专注 5–120 分钟、休息、番茄数），提示音开关、休息后自动开始开关
- 统计：今日番茄数、今日专注分钟、累计番茄数（localStorage 本机保存，刷新不丢）
- 结束时播放三音提示（Web Audio 合成，无外部资源）
- iOS Liquid Glass 液态玻璃 UI，手机/电脑自适应

## 部署
Cloudflare Workers → 从 GitHub 导入本仓库即可。无环境变量、无绑定。
